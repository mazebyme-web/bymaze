# MAZE – Make Your Own Way

אתר סטטי (Astro). כל הטקסטים בקובץ `src/content.js`, התמונות ב-`public/img`.

## הרצה מקומית
```
npm install
npm run dev      # http://localhost:4321
npm run build    # פלט בתיקיית dist
```

## Cloudflare Pages
Framework preset: Astro | Build command: `npm run build` | Output directory: `dist`

## גופן
הגופן נטען מ-Adobe Fonts. יש להוסיף לפרויקט שם את הדומיינים: bymaze.co.il, כתובת ה-pages.dev ו-localhost.

## עדיין חסר לפני עלייה לאוויר
- הצהרת נגישות ומדיניות פרטיות (חובה)
- גרסה באנגלית
- טופס יצירת קשר
- עבודות אמיתיות, מספר וואטסאפ, ניסוח סופי למיינדסט ולשירותים
